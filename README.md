# SQL Portfolio - Chinook

This repository contains SQL exercises and analysis using the Chinook database.

## How to run

This repo is self-contained: `chinook.db` is a ready-to-use SQLite database, so there's no setup beyond opening it.

```bash
sqlite3 chinook.db < basic-exercises.sql
```

Or open `chinook.db` directly in any SQLite client (e.g. [DB Browser for SQLite](https://sqlitebrowser.org/)) and run the queries from `basic-exercises.sql` one at a time.
